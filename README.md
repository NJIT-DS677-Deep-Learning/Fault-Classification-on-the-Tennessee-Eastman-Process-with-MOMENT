# Fault-Classification-on-the-Tennessee-Eastman-Process-with-MOMENT

**Claim:** "I claim that pretrained MOMENT achieves a higher macro F1 score in classifying Tennessee Eastman Process faults than the same model trained from scratch when training data is limited, and I will test it against the from-scratch model on the extended TEP dataset (Rieth et al., 2017) using 1%, 5%, 10%, 25% and 100% of the training runs."
